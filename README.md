# VISIT 2K27

The official website for the VISIT 2K27 AIML Department Fest at Vignan's Foundation for Science, Technology & Research.

## Tech Stack
- React + Vite
- Pure CSS (Custom Glassmorphism UI & 3D CSS Animations)
- Dark & Light Mode Support
- Responsive Design

## Getting Started
1. Run `npm install`
2. Run `npm run dev`
3. Run `npm run build` for production deployment
